# Website Thương Mại Điện Tử Bán Tấm Lót Giày 4D# Chính Hãng

Website bán hàng thương mại điện tử chuyên nghiệp, tối ưu cho trải nghiệm người dùng trên điện thoại di động và máy tính, tích hợp chế độ Sáng / Tối (Light Mode / Dark Mode) và trang quản trị Admin đầy đủ tính năng.

---

## 🌟 1. Thông Tin Chi Tiết Sản Phẩm Cung Cấp
- **Tên sản phẩm:** `Tấm lót giày 4D#`
- **Chất liệu:** `PU, Polyester, Spandex`
  - Đệm PU cao su non đàn hồi 4D thế hệ mới, phân tán 95% lực chấn động gót chân.
  - Vải lưới Polyester thoáng khí kết hợp sợi co giãn Spandex đa chiều dệt tổ ong kháng khuẩn, khử mùi hôi chân.
- **Hướng dẫn sử dụng:** `Cắt và đặt vào giày theo kích cỡ` (Có bảng hướng dẫn chi tiết & vạch cắt size in sẵn ở mặt đáy).
- **Bảo quản:** `Bảo quản nơi khô ráo, thoáng mát`.
- **Màu sắc:** `Đa dạng` (Đen cá tính, Xám thể thao, Xanh rêu năng động, Hồng sakura, Vàng sport).
- **Cảnh báo:** `Tránh xa lửa; không sử dụng miếng lót với mục đích khác`.
- **Xuất xứ:** `Trung Quốc`.
- **Phân loại & Giá bán:**
  - **Lót giày Nam:** `35.000 - 50.000đ` (Size chuẩn: `38 - 47`)
  - **Lót giày Nữ:** `25.000 - 45.000đ` (Size chuẩn: `35 - 41`)

## 🎨 2. Chế Độ Giao Diện (Light Mode / Dark Mode)
- **Mặc định:** Giao diện Sáng (`Light Mode`) thanh lịch, tươi sáng, chuẩn thương mại điện tử hiện đại.
- **Chuyển đổi:** Nút bấm trực quan trên thanh Navbar (biểu tượng Mặt trời / Mặt trăng) cho phép người dùng chuyển đổi tức thì giữa chế độ Sáng và Tối, tự động lưu lựa chọn vào bộ nhớ trình duyệt.

## 📸 3. Danh Sách Hình Ảnh & Video Sản Phẩm
- **Khu vực hiển thị Media chính:**
  - Trình phát video độ nét cao với đầy đủ tính năng điều khiển âm thanh, tạm dừng/phát, fullscreen.
  - Chế độ xem ảnh sắc nét kèm tính năng phóng to (Lightbox).
- **Thanh danh sách thumbnails hình ảnh & video:**
  - Hiển thị đầy đủ danh sách gồm video sản phẩm thực tế và các góc chụp chi tiết (mặt đệm, vạch cắt size, u-cup gót chân).
  - Nút mũi tên chuyển nhanh giữa các ảnh và nhãn đánh số thứ tự trực quan.

## 🛒 4. Tính Năng Bán Hàng E-Commerce
1. **Flash Sale & Social Proof:**
   - Đồng hồ đếm ngược Flash Sale và thanh trạng thái tiến độ số lượng bán.
   - Thống kê: `28.6k+ đã bán`, `3.8k+ đánh giá 4.9⭐`.
   - Thông báo đơn hàng thời gian thực ở góc màn hình.
2. **Bộ chọn Phân loại & Hướng dẫn Cắt Size:**
   - Chọn Giới tính (Nam / Nữ), Phiên bản (Tiêu chuẩn / Pro), Size giày (35 - 47), Màu sắc.
   - Popup bảng hướng dẫn cắt size trực quan 4 bước.
3. **Form Đặt Hàng Nhanh 1-Click (Checkout Form):**
   - Điền Họ tên, Số điện thoại, Địa chỉ nhận hàng, Tỉnh/Thành phố, Ghi chú.
   - Tự động áp dụng mã Voucher (Freeship Toàn Quốc 0đ, Giảm 10k, Giảm 20k).
   - Thanh toán COD khi nhận hàng hoặc Chuyển khoản VietQR.
   - Modal thông báo đặt hàng thành công + Mã vận đơn + Pháo hoa chúc mừng.
4. **Tối ưu Mobile (Responsive 100%):**
   - Thanh cố định đáy màn hình trên điện thoại (Mobile Sticky Buy Bar) gồm nút Gọi tư vấn Hotline và nút Mua ngay.

## 🔐 5. Trang Quản Trị (Admin Panel)
- **Đường dẫn truy cập:** Nhấp vào nút **"Quản Trị Admin"** trên thanh Navbar hoặc Footer.
- **Tài khoản đăng nhập:**
  - **Username:** `admin`
  - **Password:** `admin`
- **Các chức năng quản trị:**
  - **Cập nhật Website & Logo:** Thay đổi tên website, Slogan, Logo URL (có khung preview trực tiếp), Hotline, Zalo, Banner chữ chạy thông báo.
  - **Quản lý Sản phẩm & Media:** Cập nhật tên sản phẩm, chất liệu, hướng dẫn sử dụng, bảo quản, cảnh báo, khoảng giá nam/nữ, thêm/xóa URL hình ảnh sản phẩm, cập nhật URL Video.
  - **Quản lý Đơn hàng (Orders):** Xem danh sách khách hàng đặt từ form, thông tin giao hàng, số điện thoại, đổi trạng thái (Chờ xác nhận, Đang giao hàng, Đã hoàn thành, Đã hủy).
  - **Quản lý Đánh giá (Reviews):** Xem và xóa đánh giá từ người dùng.
  - **Khôi phục dữ liệu gốc:** Nút 1-click reset về dữ liệu mẫu ban đầu.

## 🚀 6. Hướng Dẫn Khởi Chạy

```bash
# 1. Cài đặt thư viện (nếu chưa cài)
npm install

# 2. Khởi chạy website (Bao gồm Backend API + Frontend)
npm start
# -> Truy cập: http://localhost:5000

# 3. Hoặc chạy chế độ Development với Vite HMR
npm run dev
# -> Truy cập: http://localhost:3000
```
